        Trident dashboard — quick reference

        A short summary of the buttons, the log tags, and the things that go wrong most often. For the full guide, open PHASE_1_ANALYST_GUIDE.md.

        Top buttons

        Status
        Read-only snapshot of the engine right now — connection, state, daily lock, currently loaded signal, any open position.
        New setup
        Open the form and start a fresh morning setup (resets every field, sets update_seq to 1). If a trade is open the engine ignores the submission — wait until the trade closes.
        Update during session
        Open the form keeping the current values, with update_seq bumped — for an intra-day recalibration (e.g. refreshing VWAP or levels at midday). If a trade is open the engine ignores the submission — the running trade always uses the levels it started with.
        Pre-fill from latest
        Load today's most recent setup file into the form so you can tweak only what's changed.
        ✨ Import from screenshot AI
        Upload one IV Smile chart screenshot. If AI is configured, Trident extracts BUY INNER/OUTER and SELL INNER/OUTER levels, ranges, DVS, and VWAP from the range panel and pre-fills the form. Cash last and basis are not extracted — enter manually if needed. Always review every value before submitting the setup.

        If submission fails

        Fields outlined in red show exactly what's wrong. Most common causes:

        Required levels are missing
        Provide both BUY INNER+OUTER or both SELL INNER+OUTER (or both pairs).
        Level ordering invalid
        Check the inequalities printed in the error message. Expected: BUY OUTER < BUY INNER < SELL INNER < SELL OUTER.
        Basis math mismatch
        futures_last − cash_last must equal basis within ±5. Quick fix: set basis = futures_last − cash_last (e.g. futures 7409, cash 7360 → basis 49).
        Invalidation boundaries
        Void values must be in ES futures terms, not SPX cash terms.

        Every field has an i icon — hover for a per-field explanation.

        Restarts & refreshes

        Browser tab refreshed
        The engine keeps running unaffected. The status band repopulates immediately from a bootstrap snapshot when the tab reconnects. The log pane starts blank — events from before the refresh are not back-filled.
        Engine process restarted
        The engine restores its full state (signal, levels, position, daily lock) from logs/engine-state.json automatically on boot. The browser tab shows "Reconnecting…" and reconnects once the server is back up — no manual action needed.
        Restart on a new calendar day
        The snapshot is date-scoped. If the engine restarts after midnight the previous day's state is discarded and the engine starts fresh — submit a new setup to begin trading.
        Trade open during restart
        Position state (entries filled, avg entry, stop, breakeven flag) is included in the snapshot and restored on boot. The engine resumes watching exits from where it left off. Check your broker position matches what the engine shows in Status.

        Log tags

        Anything with >>> ACTION: needs you to do something at the broker. The rest is informational.

        SIGNAL
        Setup file accepted and loaded.
        SIGNAL INVALID
        Setup file failed validation. The error list says which rule broke.
        SIGNAL WARNING
        Setup loaded with warnings (e.g. stale VWAP). Still trading.
        DVS GATE
        DVS > 75 — no trades today. Engine stays idle.
        SETUP
        Trade plan ready. Engine is now watching for Entry 1.
        NO SETUP
        Bias + your levels don't give a valid trade.
        ENTRY 1 / 2 / 3 (action)
        Open / scale into the position at the stated size and stop.
        BREAKEVEN (action)
        Move your broker stop to the stated level; cancel any unfilled entry orders.
        CLOSED (action)
        Exit at the broker. Reason is printed (vwap_hit, stop_loss, time_exit, invalidation, expiry, hard_profit_exit).
        LOCK
        One winning trade done — daily lock active, no more trades today. Resets automatically the next trading day.
